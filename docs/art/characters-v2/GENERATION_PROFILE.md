# Текущий профиль генерации

19 октября 2026 пользователь выбрал **DaSiWa 16, smart memory** для дальнейших
генераций. Это заменяет прежние производственные настройки 32 шага/Euler A.

- DaSiWa EpitaphEcstasy FP16, 16 шагов, CFG 6, Euler / Normal, batch 1.
- Обычное управление памятью ComfyUI: `--disable-smart-memory` убран из обоих
  настроенных launcher. Резерв 1 ГиБ, обычные приоритеты, 100% duty сохранены.
- Драйверы и зависимости не меняются. Старые графы/партии сохраняют записанные
  параметры; их не переопределяют задним числом.
- После замечания пользователя о потере рисовки новые основы редактируются
  от выбранных оригиналов на их холсте 832×1472. Пробы 768×1344 сохранены
  как неудачные исследования. Экспорт — 720×1280 с единым масштабом,
  без растяжения отдельных частей; размер генерации не равен размеру экспорта.
- Сначала нейтральные взрослые основы тела. Бельё и одежда — после отбора
  основ. Прерванная сезонная партия остаётся на паузе.
- Первая стилевая LoRA: `EroInc/candidate_400.safetensors`, UNet 0.65, CLIP 0.
  Дополнительные адаптеры обучаются при подтверждённой необходимости, только
  на отобранных собственных рисунках, с отдельной контрольной выборкой.

Набор должен различать реальные силуэты и анатомические варианты. Название
профиля не заменяет просмотр. Принятые оригиналы, альфа-слои, ошибки и
повторные попытки учитываются раздельно. В игру новый пак пока не подключается.
