# Мощность локальной генерации

По последнему указанию пользователя от **2026-10-19** включена полная
вычислительная мощность: **100%**, без искусственных пауз. Приоритеты процесса
CPU и GPU — обычные (Windows Normal, GPU class 2), резерв видеопамяти — 1 ГБ.
Установка приоритета подтверждена обратным чтением Windows API.

Ранее, 2026-10-18, действовал бюджет 80%, пониженные приоритеты и резерв 4 ГБ.
Эта настройка заменена текущим разрешением пользователя.
Настройка: `E:/Ai/ComfyUI-EroInc/gpu-budget.json`, поле `duty_percent`.
Она перечитывается перед каждым вычислительным блоком; перезапуск для изменения
этого числа не требуется. Изменение приоритетов и резерва VRAM применяется
при перезапуске через `tools/start_local_art.ps1`.

Если вернуть значение ниже 100%, ограничение действует на рабочее время
локальной генерации и обучения.
После синхронизации GPU измеряется время блока, затем добавляется пауза
`время_блока × (100 / процент − 1)`: при 80% это четверть времени вычисления.
Охвачены вызовы денойзера, кодирование текста и VAE; в обучении — проход UNet,
обратный проход и VAE. Вложенные вызовы не добавляют повторных пауз.

Это средняя доля планируемой работы процесса, а не жёсткий предел показателя
«GPU utilization» в диспетчере задач. Внутри блока возможны краткие пики 100%;
чужие приложения также используют видеокарту. Частоты, напряжение и глобальный
предел мощности драйвера не изменяются. Настройка приоритетов подтверждается
обратным чтением Windows API.

Журнал: `E:/Ai/ComfyUI-EroInc/logs/gpu-budget.jsonl`: время работы, пауза,
фактическая доля планирования и статус установки приоритетов. Ограничитель
при значениях ниже 100% добавляет паузы и сохраняет численный результат;
проверено на GPU-вычислении. При 100% обёртка сразу вызывает вычисление.

ComfyUI загружает только собственное расширение `ero_inc_gpu_budget` через
allowlist. Исходники: `tools/ero_gpu_budget.py`, `tools/comfy_gpu_budget_init.py`.
Остальные сторонние узлы остаются отключены. Тренер использует
`tools/run_sdxl_budgeted.py`. Библиотека Accelerate в изолированном окружении
зафиксирована на 1.14.0: 1.15.0 вызывает DTensor даже при обучении на одной GPU,
а Windows-сборка ROCm не содержит C10d. Отдельный неудачный пробный запуск
сохранён в `training/ero-anime-v1/hardware_probe_failed_accelerate_115`.
