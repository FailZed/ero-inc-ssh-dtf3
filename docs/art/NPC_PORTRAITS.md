# Локальные портреты случайных NPC

Для людей и полуфурри теперь используется [многослойная сборка](MODULAR_CHARACTERS.md):
тело, лицо, волосы, мимика, одежда и уши. Ниже описан запасной путь для готовых
плоских портретов, когда совместимого многослойного рига нет, в том числе антро.

Рабочее подключение находится в `scripts/portraits/npc_portrait_library.gd`.
Сама игра не запускает генератор изображений: готовые портреты создаются
локально и импортируются Godot как обычные Texture2D.

1. Положить собственные PNG в `assets/textures/portraits/npcs/`.
2. Добавить записи в `data/art/npc_portraits.json`.
3. Дождаться импорта изображений в редакторе Godot и запустить новую игру.

```json
{
  "portraits": [
    {
      "id": "fox_woman_001",
      "texture": "res://assets/textures/portraits/npcs/fox_woman_001.png",
      "morphology": "furry",
      "gender": "female"
    },
    {
      "id": "cat_man_001",
      "texture": "res://assets/textures/portraits/npcs/cat_man_001.png",
      "morphology": "semi_furry",
      "gender": "male"
    }
  ]
}
```

Допустимы `human`, `semi_furry`, `furry` и `male`, `female`, `nonbinary`.
ID должен быть уникальным и постоянным. Путь должен указывать на импортированную
текстуру внутри `res://assets/`. Существующие записи ID не переименовывать
между версиями, если уже начато прохождение.

Портреты распределяются детерминированно по ID NPC среди подходящих пола и
типа внешности, без расхода RNG симуляции. Один портрет не раздаётся нескольким
жителям. Если подходящие изображения закончились, остаётся условная иллюстрация
нужного типа внешности. Уже назначенный `appearance.portrait_id` не меняется
при переходах или восстановлении мира. Новые свободные изображения могут
заполнить пустые назначения после восстановления; механические параметры при
этом не меняются. Сюжетные персонажи не получают случайное лицо из этого пула.

Пока манифест плоских портретов пуст. Люди и полуфурри собираются из временных
слоёв, импортированных по указанию владельца; полностью фурри остаются условными
иллюстрациями до собственного пакета. Отражение героя использует тот же сборщик.
Три изображения в настройках — примеры категорий, а не портреты всех жителей.

Для DaSiWa ориентироваться на [принятый визуальный разбор](setup-v3/README.md).
Желательны портреты по грудь, одинаковый ракурс/свет, взрослые пропорции,
одетые персонажи, без текста и UI, PNG с прозрачностью при необходимости.
Человек — человеческие лицо и уши; полуфурри — человеческое лицо и звериные
уши; фурри — морда и шерсть. Хвост отдельно по образу персонажа.

Текущая схема подбирает пол и тип внешности. Подбор возраста, вида животного,
цвета волос и сменных комплектов одежды по метаданным изображения ещё не
реализован. Поэтому пул лучше готовить под фактические диапазоны нового мира.
Один seed генератора изображений не гарантирует одинаковое лицо в разных позах.
Перед расширением гардероба нужна отдельная серия согласованных изображений
или слоёв одного персонажа.
