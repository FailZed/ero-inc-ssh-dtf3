# Цветные основы по примерам пользователя

2026-10-18. Пользователь дал [папку женских референсов](https://disk.yandex.ru/d/g9fmYX-cfYvp2A/персонажи/девушки)
и уточнил: цветное рисованное 2D-аниме, полный рост; допустимы обнажённые
нейтральные тела для независимой одежды. Рабочие персонажи задаются взрослыми.

Скачаны и проверены по опубликованным SHA256 только `girls_00012_.png`,
`girls_00013_.png`, `girls_00020_.png`. Оригиналы и публичные метаданные хранятся
на E: в `E:/Ai/ComfyUI-EroInc/references/yandex_girls`, вне игры.

Ориентир рисунка: светлая кожа с мягкими локальными тенями, тонкий неагрессивный
контур, большие детализированные аниме-глаза, вытянутый взрослый силуэт,
сдержанные блики, простой фон. Пластиковый блеск и объёмные манекены не подходят.
Монохром заменяется натуральной цветной палитрой, а не повышением контраста.

PNG содержат `prompt` и `workflow`. Активная ветка исходного графа:

- DaSiWa EpitaphEcstasy — тот же установленный checkpoint.
- 720×1280, Euler ancestral / Simple, 40 шагов, CFG 3.
- В основном запросе явно указаны чёрно-белая гамма и lineart.
- В списке LoRA все элементы имеют `active: false`; зависимости от этих LoRA
  для данной пробы не заявляются. Посторонние/отключённые ветви графа не запускаются.

Раскраска `girls_00013_.png` выполняется локальным img2img. В журнале сохраняются
хэш исходника, запрос, настройки и результат. Это производная цветная проба по
переданному пользователем рисунку, а не новое изображение с нуля. Она пока не
является разделённым игровым набором слоёв.

Для окончательного набора требуются отдельные тела, головы, глаза, рот, брови,
передние/задние волосы и одежда. Перекрещенные ноги исходника неудобны для общего
гардероба: производственные основы должны иметь общую устойчивую позу.

Первые свободные локальные пробы с 3D-подобным рисунком забракованы. Проба
`female_average_00002_.png` держит аниме-стиль, но содержит платье и слишком малые
поля — это тоже не готовая телесная основа.
