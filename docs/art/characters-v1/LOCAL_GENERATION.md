# Локальная генерация персонажей

Установка: `E:/Ai/ComfyUI-EroInc`. Интерфейс: <http://127.0.0.1:8188>.
ComfyUI 0.41.0 из официального AMD portable-релиза; встроенные Python 3.12.10,
PyTorch 2.9.1 + ROCm 7.2.1. Проверены матричное умножение и свёртка на RX 7800 XT.
Драйвер и системный Python при этой установке не менялись.

Модель: DaSiWa Illustrious / Anime, **EpitaphEcstasy**, version 3012006,
`DasiwaIllustriousAnime_epitaphecstasy.safetensors`, 6 938 115 222 байта.
SHA256: `44670E67C55F059116171EE8538875DA3ABF624FBDAACE6D1A7AC2D9617F0211`.
Исходный файл скачан пользователем с Civitai; проверенная копия установлена на E:.
Модель остаётся вне проекта и не включается в сборки игры.

Запуск из проекта:

```powershell
& ./tools/start_local_art.ps1
& ./tools/start_local_art.ps1 -Stop
```

Также на E: созданы `Start-ComfyUI.cmd` и `Stop-ComfyUI.cmd`.
Сервер работает только на 127.0.0.1; облачные API-ноды и сторонние custom nodes
отключены. Кэш, input/output, временные файлы, пользовательские workflows и логи
находятся внутри каталога установки на E:.

Профили и полный текст запросов: `local-profiles.json`. Подготовлено по восемь
телосложений на пол. Это задания и критерии отбора, а не заявление о готовности
16 игровых тел. После изучения примеров пользователя настройки изменены на
Euler ancestral / Simple, 40 шагов, CFG 3, 720×1280, один персонаж в кадре.
Полный рост означает наличие головы, кистей и
обеих стоп, а не только высокое разрешение.

Дополнительно установлен [xinsir OpenPose SDXL](https://huggingface.co/xinsir/controlnet-openpose-sdxl-1.0)
(Apache-2.0, SHA256 `b8524e557a7df60d081f5d4a0eb109967d107df217943bf88c2d99b9ebcc06c5`).
Он используется для общей позы по флагу `--pose` в командах `prepare` и `generate`.
По умолчанию остаются свободные пробы. Карта суставов создана отдельно для EroInc;
изображения School в контроле не используются. Создание карты: `tools/prepare_character_pose.py`.

```powershell
$artPython = 'E:/Ai/ComfyUI-EroInc/runtime/ComfyUI_windows_portable/python_embeded/python.exe'
& $artPython ./tools/local_character_art.py prepare
& $artPython ./tools/local_character_art.py verify
& $artPython ./tools/local_character_art.py generate --profile male_average --watch
& $artPython ./tools/local_character_art.py generate --profile female_average --watch
& $artPython ./tools/local_character_art.py generate --profile female_slim --pose --watch
```

`generate` создаёт одно задание. Занятая очередь не дополняется автоматически.
Без `--watch` команда сразу возвращает ID; состояние запрашивается командой
`status --prompt-id ID`. При изменении запросов сначала снова выполнить `prepare`.
В интерфейсе ComfyUI: «Рабочие процессы» → EroInc → нужный профиль.

Пользователь выбрал рисунок `female_slim_00001_.png` как стиль серии. Его
собственная DaSiWa-копия находится в `input/derived/style_target_dasiwa.png`.
Флаг `--reference` включает полное img2img этого рисунка; голова и тело
перерисовываются вместе. Маска с неизменной головой для изменения массы тела
больше не используется. Источник и его SHA256 записываются в каждый запуск.
Команда `prepare --pose --reference` сохраняет эти графы для интерфейса.
Запуск конкретной пробы: `generate --profile female_average --pose --reference --watch`.
Все мужские и женские игровые тела создаются на DaSiWa; старые листы ImageGen
и экстремальные `female_full` не входят в производственный набор. Учёт отбора —
`body-review.json`. Утверждение стиля не означает готовность игровых слоёв.

Результаты PNG с графом и запросом: `E:/Ai/ComfyUI-EroInc/output/characters_v1`.
Полные сведения о каждом запуске: `E:/Ai/ComfyUI-EroInc/runs`.
Сырые пробы автоматически в Godot не импортируются. До импорта нужны визуальный
отбор, прозрачность, единые опорные точки, соответствующая одежда и проверка в игре.
Неудачные результаты не являются игровой основой и отмечаются отдельно.

Редактирование с явной маской: `tools/local_art_edit.py`. Белая область маски
перерисовывается DaSiWa, остальные пиксели сохраняются композитингом. Проба
`prepare_body_outpaint.py` использует только наш ранее созданный лист ImageGen;
результат ещё не прошёл отбор по швам и стилю.
Без `--mask` этот же инструмент выполняет img2img. Параметры задаются флагами
`--denoise`, `--steps`, `--cfg`, `--sampler`, `--scheduler`.
Редактируемые графы сохраняются в «Рабочие процессы» → EroInc_Color.

После проверки серии выбран штатный режим GPU и FP16 для текстовых энкодеров,
`--disable-smart-memory`, `--disable-async-offload`, резерв VRAM 4 ГБ. Пробный
CPU-режим `--lowvram --fp32-text-enc` был медленнее и больше не используется.
Два последовательных запуска после изменения заняли 46,86 и 40,29 секунды.
Сервер запускается отсоединённым Python-процессом с настоящими файловыми
дескрипторами логов, а не через временный PowerShell-посредник. Логи продолжают
записываться после завершения команды запуска.

Новая карта `controls/adult_front_idle_v2.png` добавляет симметричные 68 точек
лица к общей позе; это самостоятельно построенный технический контроль.
Создание: `tools/prepare_character_pose.py --detail`. Карта v1 сохранена для
воспроизводимости старых запусков.

Удаление фона выполняет отдельное окружение на E: с rembg 2.0.85,
BiRefNet-General-Lite и ONNX Runtime CPU. Изображения никуда не отправляются.
Используется явный свободный BiRefNet, а не платный облачный сервис.
Исходный PNG сохраняется; прозрачная копия получает метаданные и `.qa.json`.

```powershell
& 'E:/Ai/ComfyUI-EroInc/postprocess/Scripts/python.exe' ./tools/prepare_character_cutout.py SOURCE.png TARGET.png
```

`assets/art_source/characters_v1/.gdignore` исключает исследования из импорта и
сборок Godot. Проверенные игровые слои размещаются отдельно после визуального отбора.

Рабочий набор портретов и сохранения эта установка не изменяет.

Первый набор тел: `assets/art_source/characters_v1/bodies_v2` (16 PNG).
Это отдельные слои от шеи до стоп: головы, лицо, волосы и одежда не запечены
в тело. Техническое извлечение — `prepare_body_layers.py`: удаление альфы выше
границы шеи, удаление отделённых фрагментов, равномерное масштабирование без
деформации анатомии. Холст 720×1280, верх тела y=245, линия стоп y≈1244;
точка крепления головы записана индивидуально в `.qa.json` и манифесте.
Исходные PNG с целыми фигурами и неудачные головы остаются вне игрового набора.
Мужские половые признаки сохранены согласно позднему уточнению пользователя.

Для различимых пропорций добавлены небольшие вариации каркаса: ширина плеч,
бёдер и расстояние до рук. Команда `prepare_body_build_poses.py` создаёт 16
самостоятельных технических карт. Они не являются растяжением готового рисунка.
Визуальный выбор тел пока не означает точного покрытия всех параметров School.

Проверка PNG, прозрачности, полей, опорных точек и цепочек происхождения:

```powershell
& 'E:/Ai/ComfyUI-EroInc/postprocess/Scripts/python.exe' ./tools/build_body_pack.py
```

Манифест отмечает оставшиеся работы: отдельные головы/лицо/волосы, одежда по
фигурам, проверка стыков и рисунка в игре. LoRA не обучалась. Старые экстремальные
пробы и неудачные лица не используются как тренировочная выборка.
