# Профессии NPC

28 октября 2026. Доработка A03 после аудита механик. Это собственная модель EroInc; паритет чисел School не заявляется.

## Что изменилось

Автономные работники используют профессиональные профили из 30 легальных вакансий игрока. У профиля есть название, навык, входной уровень, место, часы и ставка. Три нелегальные вакансии не превращены в безрисковый фоновый доход: для них нужна отдельная модель последствий NPC. У игрока все 33 вакансии сохранены.

Профессия случайного работника выбирается по уже имеющимся навыкам, интересам и совместимости с обязательным расписанием. ID разрывает равенство кандидатов, но не заменяет навык. Рабочее место берётся из профессии; случайный выбор другой торговой точки удалён. Имеющийся рабочий блок приводится к часам и длительности вакансии с сохранением допустимых рабочих дней. Обязательные занятия не перезаписываются.

Работник с пустыми навыками получает начальный опыт только в выбранной профессии: уровень навыка 1 в 18–22 года, 2 в 23–29 лет, 4 с 30 лет. Это один раз при создании автономного персонажа; загрузка и повторная инициализация опыт не выдают. Явно заданные навыки не заменяются возрастной оценкой. Студентам и другим неработающим жителям случайная профессия не навязывается.

## Рост, оплата и прерывания

Игрок и NPC используют `core/career_progress.gd`: уровень навыка `floor(sqrt(raw / 10))`, максимум 10. Автоматические карьерные ступени требуют уровней навыка 0, 2, 4, 6, 8. Часы работы и деньги сами по себе ступень не повышают. Профессиональная практика развивает навык своей профессии; работа даёт 2 сырых единицы навыка за продуктивный час. Надбавка ступени — 8%.

Часовая ставка рассчитывается из оплаты и длительности соответствующей автоматической смены игрока. Платится продуктивное время. Поездка не даёт денег и опыта. Если работа прервана уходом, встречей или общей системой приоритетов, выполненная часть оплачивается один раз; остаток часа не оплачивается. Дробные остатки денег и навыка сохраняются, поэтому короткие части смены не создают и не теряют целые награды. Повышение после изучения навыка действует для следующего рабочего отрезка, без пересчёта уже начатого.

У обычного профиля дневной предел — две длительности вакансии, максимум 600 минут. После исчерпания лимита оставшееся рабочее окно освобождается; следующий день сохраняет свои обязательства. Календарь учитывает дорогу, встречи, лечение и уход. Явно объявленное обязательство не исчезает только потому, что у тестового/сюжетного персонажа ещё нет профиля зарплаты. Дни недели из JSON сравниваются как целые значения, включая восстановление снимка.

В карточках NPC показаны профессия, ступень, связанный навык, следующий порог, ставка, место и рабочие часы. В истории остаются заработок и настоящие повышения. Открытие карточки состояние и RNG не меняет. Стиль окон и портреты не заменялись.

## Контракт авторской профессии

Поддерживается поле `employment` в шаблоне NPC либо аргументе `social.generate`. Внутренние `mind.employment` и счётчики содержимое мира напрямую не записывает.

```gdscript
# Пример структуры шаблона, не новый канонический NPC.
catalog.npc_templates.authored_worker = {
    "age": 30,
    "role": "worker",
    "home": "bedroom",
    "schedule": [{
        "activity": "work",
        "location": "riverside_cafe",
        "hours": [600, 1080],
        "weekdays": [1, 2, 3, 4, 5],
        "mandatory": true
    }],
    "employment": {
        "job": "cafe_orders",
        "skill_level": 2,
        "workplace": "riverside_cafe"
    }
}
simulation.command("social", "generate", {
    "id": "authored_worker",
    "template": "authored_worker"
})
```

Альтернативно тот же словарь `employment` передаётся в аргументе генерации. Если он одновременно есть в шаблоне и аргументе, противоречивые назначения отклоняются. Ровно три поля: `job`, `skill_level`, `workplace`. Начальный уровень 0–10 должен соответствовать входному требованию вакансии; он переводится в сырой опыт `10 × level²`. Последующее обучение не сбрасывается к этому начальному уровню.

Для кафе используется `cafe_orders` / `cooking` / `riverside_cafe`; для продуктовой лавки в нынешней географии — `shop_assistant` / `sales` / `north_shops`. Новых персонажей, локаций и географии эта доработка не создаёт.

Проверки при генерации:

- Профессия есть в действующем каталоге NPC, навык — в каталоге навыков; персонаж совершеннолетний, роль `worker`.
- Место существует и совпадает с местом вакансии; для работы из дома — с домом NPC.
- Есть явные обязательные блоки `work` с правильным местом, часами и днями недели. Они укладываются в часы вакансии и открытия места, не пересекаются друг с другом и обязательной учёбой. Между обязательными блоками в разных местах требуется как минимум 15 минут; точное время дороги дополнительно проверяет действующий планировщик.
- Рабочее время не превышает 600 минут в день. Полноценная авторская смена, например 10:00–18:00, не сокращается до длительности разовой подработки. Дневной бюджет учитывает объявленную смену.

Назначение проверяется **при генерации**, когда собран действующий каталог. Ошибка возвращается до добавления NPC; команда откатывает изменения и RNG. Нет подстановки случайной профессии при ошибке. Примеры отказов: `unknown_employment_job`, `employment_skill_required`, `employment_worker_required`, `employment_workplace_conflict`, `employment_schedule_required`, `employment_hours_conflict`, `employment_schedule_conflict`, `employment_day_too_long`, `employment_assignment_conflict`.

Авторский NPC не получает другую случайную профессию, другое место или рабочие часы. Он не берёт незапланированные смены до работы или в выходной. Загрузка проверяет связь исходного назначения, фактической профессии, навыка и расписания. Ночные авторские смены через полночь этим контрактом пока не принимаются; существующая общая поддержка ночных обязательств сохранена.

## Формат и проверки

Вместо `mind.career_level`, рассчитанного через программирование, используется `mind.employment = {job, day, minutes_today, paid_minutes, earnings}`; ступень вычисляется из навыка. Версия mind — 2, основной снимок — 10. Предыдущие форматы отклоняются без миграции; пользовательские файлы сохранений не переписывались.

`tools/test_npc_employment.ps1` проверяет начисления, границы навыков, прерывания, авторские назначения, часы и лимиты, неизменность просмотра и межпроцессное продолжение незавершённой работы. `tools/test_mechanics.ps1 -NpcCareersOnly -Isolated -Pack` выполняет целевые регрессии NPC, календаря, ухода и восстановления из отдельного PCK без недельного нагрузочного прогона. Все процессы используют Dummy audio.

Нативные окна для новой вставки профессии не запускались: управление экраном закреплено за UI-исполнителем. Проверены действительные узлы карточки в headless; визуальная проверка компоновки передана через файл координации. См. [отчёт](verification/npc-careers-2026-10-28/report.json).
