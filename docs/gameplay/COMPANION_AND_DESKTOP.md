# Встречи с NPC и desktop-сборки

Проверено 28 октября 2026 года, Godot 4.7.2 stable.

## Изменения

- Live2D-встреча открывается из профиля NPC, раздела «Время вместе». Предложение занимает 1 минуту, завершённый жест — 5 минут.
- Доступны рука, голова и щека. Проверяются присутствие, взрослый возраст, здоровье, занятость, доверие, близость, личные границы; для щеки — взаимное романтическое влечение. NPC может отказаться.
- Прикосновение мышью/касанием и кнопка вызывают одну игровую команду. Меняются доверие, комфорт, симпатия и социальная потребность; событие остаётся в истории NPC. Награды используют общий дневной бюджет поддержки, повтор ограничен тремя игровыми часами.
- Незавершённая принятая встреча сохраняется и восстанавливается детерминированно. Перед наградой проверяются актуальные обстоятельства; отмена не ухудшает отношения.
- Добавлены готовые Cubism-библиотеки macOS universal и Windows x86_64, воспроизводимая сборка из официального SDK, переносимые запускатели, тесты, экспорт и CI.
- Исправлены первый импорт Dialogic, потеря имён говорящих при регистрации ресурсов, создание лишних узлов подсистем, удержание скрипта условий Quest Weaver, ссылка на импортированный кэш вместо исходной иконки.
- Несовместимое сохранение больше не запускает пролог заново: пользователь получает сообщение в меню. Невосстановленное состояние нельзя сохранить поверх слота. Файлы старых сохранений не изменяются; миграция не добавлена.

macOS проверена нативно на Apple M4 Pro. Windows x86_64 проверена через Wine 10: чистый импорт, шесть моделей, встреча, несовместимое сохранение, идентификаторы сценария, запуск EXE и графический экран с OpenGL. Это не проверка на физическом Windows-компьютере; для неё добавлена отдельная Windows-задача CI, удалённый прогон ещё не выполнялся.

Нативные снимки экрана просмотрены. В меню и проверках Live2D больше нет утечек, найденных при первоначальном запуске. В отдельных сценарных прогонах при завершении ещё встречаются предупреждения о незавершённых объектах; это не объявляется полностью устранённой утечкой всего проекта. Информационные сообщения SDK Cubism выводятся самим расширением как WARNING.

Логи: `.artifacts/tests`, `.artifacts/export`, `.artifacts/windows-*.log`. Изображения: `.artifacts/tests/captures/companion` и `.artifacts/windows/captures/companion`. Эти каталоги локальные и не включаются в Git.

## Что остаётся по содержанию

Это рабочая интеграция существующих систем жизни NPC с Live2D, а не завершение всей игры. Учебный образ не заменяет индивидуальную внешность персонажа: ещё нужны собственные модели для NPC, мужские/антропоморфные варианты, авторские анимации и эмоции. Для остальных тел действия доступны с обычным портретом. Новые сюжетные главы, индивидуальные диалоги и длительный баланс экономики/отношений требуют отдельного содержательного прохода. Android, публичная подпись и публикация сборок в эту проверку не входят.
