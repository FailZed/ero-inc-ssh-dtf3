## Окна свободного режима

Разговоры теперь показывают собеседника по центру, ответы справа и реплики
снизу. Зеркало, случайные жители и основные сюжетные говорящие используют
[общую многослойную сборку](../art/MODULAR_CHARACTERS.md). Арт временный, ограничения
ригов и план замены на собственные изображения описаны там же.

| Окно | Что доступно |
| --- | --- |
| Здесь и сейчас | Потребности, контекстные действия комнаты, присутствующие NPC |
| Карта | Переходы, стоимость времени, часы работы, ожидание |
| Персонаж | Характеристики, опыт, очки, навыки и перки |
| Сумка | Вес, предметы, еда, экипировка и установка оборудования |
| Телефон | Контакты, сообщения, звонки, приглашения и встречи |
| Люди и отношения | Цели, занятия и настроение жителей; чувства к игроку, связи между NPC и история событий |
| Профиль собеседника | Общение, прогноз разговора, подарки, история, обещания, отношения, свидания и рискованные действия |
| Журнал | Задачи, достижения, готовые события и последствия действий |
| Занятия и учёба | Тренировки, выбранные дисциплины, домашняя работа, восстановление после отчисления, мини-игры |
| Работа и деньги | Торговля, банк, работы, смены, заказы, стриминг, журналистика и активы |
| Мой клуб | Участники, задания, бюджет, зарплаты, проекты и выборы |
| Мой дом | Аренда/покупка, жильцы, имущество и планировка мебели |
| Самочувствие | Потребности, лечение, травмы, длительные состояния, семья и последствия правонарушений |

Бой открывает отдельное состояние с очками действий, стойками, приёмами и
журналом. Начатую мини-игру нужно завершить или покинуть с потерей ставки.
Нельзя обходить активную встречу переходом в другой раздел.

I — сумка, C — персонаж, J — журнал, M — карта, P — телефон, R — люди, Esc — меню.
Кнопки работают мышью и стандартной навигацией Control с клавиатуры; отдельная
пользовательская раскладка геймпада и проверка сенсорного управления ещё впереди.
Время и потребности меняются через игровые действия, а не при чтении меню.
Недоступные действия показывают причину; ошибочная команда не расходует ресурсы.

## Архитектура

`scripts/gameplay/gameplay.gd` — единственный основной владелец Simulation.
UI вызывает `Gameplay.execute`, затем отображает подтверждённое состояние.
`presentation.gd` содержит русские названия, сообщения и расширения каталога
основной игры. `curriculum.gd` связывает выбор дисциплин с действующими уроками;
пропуски невыбранных дисциплин не штрафуются.

Движение по карте остаётся внутри `game.tscn`; изменяется логическая локация и
фон. Это сохраняет контекст Dialogic и исключает двойную оплату времени.
Старые `LocationManager.go_to` блокируются новым владельцем переходов.
Во время главы используется отдельный ограниченный граф `guided_story.gd`.

Quest Weaver получает тот же инвентарь через `quest_inventory_controller`;
его существующие цели не переписаны. Новые задачи runtime отображаются в журнале.
Новые авторские квесты нужно связывать с успешными действиями и собственными
objective ID, а не добавлять игроку кнопку ручного увеличения прогресса.

## Состояние и существующие сохранения

Реализация слотов, Dialogic Save, загрузочное меню и карточки слотов не менялись.
Снимок симуляции, конфигурация и флаги главы добавляются в существующий
расширяемый словарь `Dialogic.VAR.var_storage.World`, который уже сериализуется
Dialogic. Это новые игровые данные внутри прежнего механизма, без нового
формата файлов слотов или миграции пользовательских файлов.

В GameSession изменена только проверка очков создания персонажа: бюджет
соответствует выбранной сложности, остаток можно сохранить для развития.
Старый слот без нового снимка продолжает свой сюжет; открытие мира ему не
присваивается автоматически. Другой хеш каталога отклоняется вместо тихого
сброса прогресса. Совместимость будущих изменений каталога потребует явной
миграции. Проверялось восстановление в памяти; проверка на реальных
пользовательских слотах не выполнялась.

## Исправления Dialogic

- `Core/DialogicGameHandler.gd`: смена ревизии timeline отменяет старое событие,
  ожидавшее снятия паузы. Это предотвращает запуск чужого индекса после комнаты
  исследования или восстановления состояния.
- `Modules/Character/subsystem_portraits.gd`: проверка живого узла после
  асинхронной загрузки и наличия дочернего портрета перед подсветкой.
- Все используемые говорящие зарегистрированы файловыми `.dch`; префиксы
  имён с пробелами заключены в кавычки. Это устранило аварийный выход на
  временном ресурсе неизвестного говорящего. Карта — `docs/story/CHARACTERS.json`.
