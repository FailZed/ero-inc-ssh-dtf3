# Давление, нравственные поступки и противодействие

Реализация 28 октября 2026. Основной runtime, схема 12. Сценарная опора: пользовательский документ [EroInc](https://docs.google.com/document/d/17MGdEhAfeDBCamzr-jgrxNOOKDjFBuj_J9Xi0HMJFUQ/edit). Через браузер прочитаны пояснения к миру/персонажам и начало ветки «Проблемы Оливера» до выбора вмешательства; полный документ не заявляется прочитанным. Экспорт недоступен, исходный документ не изменён.

Из прочитанного взяты направления: длительная травля, страх свидетелей, безнаказанность при формальном запрете, выбор более слабой цели, цена вмешательства и доброжелательные персонажи, готовые защищать других. Вид, пол и внешность не задают нравственность генератору. Именные сцены не переписываются; поведение новых ситуаций определяется индивидуальными чертами и историей.

## Реализуемый цикл

Мотив → доступная цель → предупреждение → время на ответ → последствие → память агрессора. Четыре вида: вымогательство (`extortion`), травля (`intimidation`), клевета (`slander`), срыв проекта (`sabotage`). Мотивы выводятся из честности, справедливости, корысти, мягкости, смелости, амбиций и обиды к конкретному человеку. Успешное давление повышает безнаказанность; сопротивление и разоблачение повышают ожидаемую цену следующего нападения. Фиксированной шкалы «добро–зло» нет.

Самостоятельные попытки начинаются после открытия города, при включённой жизни NPC. Требуется местная встреча и доступность агрессора. Не более двух одновременных случаев, одного на цель/агрессора, паузы между попытками. NPC могут выбирать других взрослых NPC, не только игрока. Сведения о незамеченных событиях не раскрываются игроку.

## Контракт интерфейса

`sim.services.antagonism.inspect()` — чистая модель: `enabled`, `cases`, `history`. Случай содержит `id`, `actor`, `target`, `kind`, `label`, `description`, `location`, `deadline`, `status`, `evidence`, `witnesses`, `ally`, `loss`, `result`, `responses` и `allies`. `responses`: `id`, `text`, `minutes`, `blocked`; `allies`: `id`, `name`, `blocked`. `status`: `open`, `resolved`, `cancelled`. Не объявлять `resolved` победой: смотреть текст результата и ущерб.

Все ответы через `Gameplay.execute("antagonism", "respond", {id:case_id, choice:response_id, ally:optional_npc_id})`. Доступные ответы:

| ID | Последствие |
| --- | --- |
| `document` | Сохранить угрозу, одно очко свидетельств |
| `investigate` | Проверить хронологию, ещё одно подтверждение |
| `ally` | Попросить подходящего знакомого о поддержке; свидетель помогает доказательствами, присутствующий союзник уменьшает физический ущерб |
| `refuse` | Проверка сопротивления с учётом сил, поддержки и безнаказанности; неудача оставляет другие варианты |
| `pay` | Реально передать деньги вымогателю; передышка, рост его безнаказанности |
| `secure` | Защитить материалы от саботажа за домашним компьютером |
| `report` | Подать заявление при двух подтверждениях; успех не гарантирован, повторный бросок того же ответа запрещён |
| `expose` | Предъявить свидетельства окружению, опровергнуть клевету и испортить отношения свидетелей с агрессором |
| `evade` | Завершить физическую угрозу после реального ухода из места встречи |

Свидетели бывают поддерживающими, молчащими и пособниками; выбор зависит от ценностей, отношений и оценки риска. Поддержка не гарантирована даже при знакомстве. После наступившего ущерба ещё неделю доступны сбор свидетельств и разоблачение. Здоровье, деньги и испорченный результат работы сами не восстанавливаются.

События `pressure_notice`, `pressure_started`, `pressure_resolved`. Уведомление содержит русский `text`; сообщения также попадают в существующую переписку с участником. Сроки включены в планировщик. Для сцен: `antagonism.stage {id:actor_id,target:"player"|npc_id,kind}`; этот вход проверяет возможность и мотив, UI не должен предлагать игроку создавать нападения.

Файлы `scripts/mechanics/antagonism.gd`, `core/antagonism_validation.gd`, `data/mechanics/antagonism.json` и интеграцию backend изменяет агент механик. UI/сцены остаются за UI-агентом. Пользовательские сохранения не переписываются.

## Подключение и результаты проверки

Ответы уже включены в `city_dialogue.present/choose`: в переписке/разговоре с агрессором или пострадавшим появляются варианты по случаю, с подходящим знакомым — просьба о поддержке. Ключи `pressure:case_id:response` принадлежат backend; UI должен отправлять обычную команду выбора с текущим `turn`. Проверяются срок диалога, повтор ответа и устаревший экран. `pressure_notice` отображается обычным уведомлением/журналом, тексты ошибок переведены. Дополнительную сводную панель случаев согласовано подключить с UI-агентом; её готовность здесь не заявляется.

Физическое давление наносит реальные повреждения тела, только если участники встретились к сроку вне приватных домашних комнат. Присутствующие союзники уменьшают ущерб, пособники увеличивают; оставшаяся без контакта угроза завершается без нападения. Клевета временно снижает восприимчивость именно слышавших её NPC, не создаёт всемирного знания и не переписывает историческое доверие. Разоблачение снимает этот эффект. Саботаж ухудшает качество/увеличивает замечания реального активного заказа. Успешное заявление также списывает взыскание с денег агрессора.

Планировщик продолжает считать действия на копии, но не предсказывает новые случайные нападения: `social_risk_unmodelled` явно указывает на это ограничение. Уже известные сроки сохраняются. При проверке восстановления исправлено округление изменений потребностей NPC в `adult_health.adjust` и `pregnancy_wellbeing._adjust`: суммы считаются в целых единицах точности, поэтому JSON не меняет дальнейший результат.

Проверка 28 октября 2026: `python3 tools/test_mechanics_depth.py` — 284 проверки, 0 ошибок; `pwsh -NoProfile -File tools/test_mechanics.ps1 -Isolated -Pack` — 2674 проверки, 0 ошибок. Покрыты автономное начало, индивидуальные мотивы, укрытие дома, защита пролога, перевод денег, свидетельства/повторные ответы, помощь/молчание/пособничество, NPC против NPC, повреждения, слухи, саботаж, существующий телефонный диалог, повреждённые снимки и одинаковое продолжение после JSON. Проверка логики не заменяет визуальную проверку экрана.

Границы: пока нет долгих многоходовых заговоров, организованных фракций, слежки по городу, полноценного преследования после ухода и отдельного шантажа секретами. Именные ветки исходного сценария не перенесены этим изменением; это работающая общая система давления и противодействия в свободной игре.
