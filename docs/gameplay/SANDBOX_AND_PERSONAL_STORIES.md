# Песочница, личные истории и состояния персонажей

27 октября 2026 года, Godot 4.7.2. Продолжение интеграции механик в EroInc.
Репродуктивную систему параллельно ведёт другой исполнитель; её актуальный
контракт описан в [REPRODUCTION.md](../mechanics/REPRODUCTION.md).

## Как начать

«Новая игра» → «Песочница · жизнь в городе» → настройки жителей → сложность.
Перед стартом доступны переключатель «Беременность и появление детей» и
начальные деньги от 100 до 1000 ¤. Выбор песочницы первоначально ставит сложные
условия; затем можно выбрать спокойный, обычный или собственный режим.

Игра открывает домашнее зеркало для создания героя. После подтверждения сразу
начинается свободная жизнь в городе с 08:00. Пролог, первая глава, учебный
маршрут и обязательный вводный квест не запускаются. Личные дела знакомых
остаются добровольными. История сохраняет прежний путь через пролог и зеркало.

Старт по умолчанию: 250 ¤, снимаемое жильё с настоящим сроком следующей оплаты,
плита, три готовых обеда, книга, две крупы и два овоща. Потребности, расходы,
время, работа, учёба, отношения, самостоятельные решения NPC и семейные
системы действуют сразу. Все установленные игровые системы используют общий
runtime; требования навыков, денег, оборудования, времени и отношений остаются
частью игры. Учебные дисциплины доступны без сюжетного выбора факультатива.

Песочница не выдаёт награды за завершение главы и не добавляет сюжетных NPC
помимо выбранного случайного населения. Повторный вызов начала не выдаёт
стартовые ресурсы. Режим и настройки записываются в обычный `World`.

## Личные истории NPC

Вход: «Люди и отношения» → профиль человека → «Личная история». Начатые и
завершённые истории доступны также из журнала. Нужны знакомство, присутствие
собеседника, доверие не ниже 5, отсутствие серьёзной обиды и время для разговора.
Просмотр страницы сам по себе не двигает часы и не меняет RNG.

| Цепочка | Действия в мире |
| --- | --- |
| Асука: общее дело | Осмотреть парк и кафе у реки; действительно помочь Асуке |
| Оливер: незаконченная работа | Почитать; успешно пройти цифровую тренировку |
| Элли: работа и отдых | Сделать домашнюю работу; выделить время на досуг |
| Соседство: общий стол | Приготовить овощной обед; подарить его этому человеку |
| Создатель: маленький проект | Поработать над реальным заказом; помочь собеседнику с делом |
| Новый знакомый: город становится знакомым | Посетить парк и пляж; поддержать этого человека |

Это шесть собственных цепочек по восемь узлов — 48 узлов. Первые три закреплены
за именованными персонажами. Случайные взрослые жители получают одну из трёх
повседневных цепочек по постоянному ID; прогресс хранится отдельно для каждого
человека. Это начальный набор индивидуального содержания, а не уникальный
сценарий для каждого возможного жителя города.

В каждой цепочке можно отказаться, завершить дело в небольшом масштабе или
дойти до общего результата. Разговоры тратят указанное в данных время и энергию.
NPC остаётся на встрече на время выбора. Состоявшаяся концовка один раз меняет
отношения, выдаёт опыт и остаётся в личной памяти. Повторное нажатие старого
ответа или завершённой концовки не приносит награды.

Цели засчитываются после успешных команд обычных систем. Для поездок нужны
разные указанные места; для подарка и помощи — правильный собеседник. Неудачная
цифровая попытка и отклонённое социальное действие не закрывают цель. Кнопки
ручного начисления прогресса нет. Проверяются ссылки графа, выборы в истории,
порядок времени и частично выполненные цели.

## Визуальные состояния

Общий сборщик портретов получает потребности, травмы и этап беременности из
runtime. Низкая энергия/выспанность и самочувствие меняют нейтральное выражение,
усталость слегка охлаждает тон, низкая гигиена добавляет приглушённые пятна.
Травмы головы и рук от 15 показывают повязки с отдельными координатами двух
текущих ригов. Нулевые записи уже заживших травм не оставляют состояние ранения.

Для этапов беременности 2–4 действует постепенное изменение области живота
одним шейдером на совмещённых слоях тела и одежды. Профиль героя, портреты NPC
и адаптер Dialogic используют общий механизм. Сам просмотр не меняет состояние,
экипировку, внешность персонажа или случайность симуляции.

Используется существующий временный многослойный арт, без новых изображений.
Деформация — технический вариант для текущей позы, не финальный анатомический
набор беременности. Для окончательного качества ещё нужны собственные
согласованные позы, одежда, варианты состояния и полноценный антро-риг.
Происхождение и ограничения набора: [MODULAR_CHARACTERS.md](../art/MODULAR_CHARACTERS.md),
утверждённый стиль: [STYLE.md](../art/characters-v2/STYLE.md).

## Точки входа для разработки

| Область | Файл |
| --- | --- |
| Настройки режима и беременности | `scripts/mechanics/setup_config.gd`, `scripts/ui/gameplay/world_setup.gd` |
| Вход в открытый мир | `scripts/gameplay/sandbox_flow.gd`; `Gameplay.open_sandbox()` после зеркала в `scripts/core/game.gd` |
| Подключение личных историй | `scripts/gameplay/main_simulation.gd`, общий текущий runtime |
| Данные историй | `data/mechanics/npc_stories.json` |
| Правила историй и наблюдение за действиями | `scripts/mechanics/npc_stories.gd` |
| Окно и журнал | `scripts/ui/gameplay/personal_story_window.gd`, `gameplay_shell.gd` |
| Вычисление состояния | `scripts/portraits/character_state.gd` |
| Отображение | `character_state.gdshader`, `character_state_overlay.gd`, `layered_character_view.gd` в `scripts/portraits` |

Переключатель беременности передаёт тег `pregnancy` в обычные preferences.
Репродуктивная подсистема соблюдает его при вычислении возможности беременности;
прямой запуск соответствующего состояния тоже отклоняется. Её код и сцены в
этом проходе не переносились и не заменялись.

Текущий runtime использует main-схему 8 и точный хеш текущего каталога.
Миграции прежних схем и обёртки альтернативных игровых runtime удалены по
указанию владельца до релиза. Несовместимый снимок отклоняется без изменения
состояния. Пользовательские файлы сохранений не редактируются.

## Проверка

`tools/test_sandbox.ps1`: 77 проверок правил и цепочек, 11 проверок настоящего
пути через игровую сцену и зеркало, запись/чтение тестового `World` в разных
процессах с совпадающим продолжением частично выполненной цели.

Общая регрессия, экспортируемый самостоятельный runtime и пять вариантов
прохождения первой главы зафиксированы в [протоколе](verification/sandbox-2026-10-27/report.json).
Самостоятельный PCK проверяет свои системы; личные истории и вход в песочницу
проверяются в основной игре, а не считаются покрытыми этим PCK.

Все процессы запущены с `--audio-driver Dummy`. Семь изображений в каталоге
протокола — захваты нативного Godot на управляемом тестовом мире 1366×768,
проверенные визуально; это справочные примеры интерфейса, не снимки
пользовательского сохранения и не обещание финального качества арта.

Граница результата: игровые аналоги подключены к EroInc; полного переноса всех
сюжетов, изображений и чисел School этот этап не заявляет. Матрица покрытия:
[PARITY_MATRIX.md](../mechanics/PARITY_MATRIX.md).
