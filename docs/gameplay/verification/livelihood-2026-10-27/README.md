# Приёмка работы и самостоятельной жизни

27 октября 2026, Godot 4.7.2. Правила и входы: [LIVELIHOOD.md](../../LIVELIHOOD.md).
Машиночитаемый протокол: [report.json](report.json).

82 проверки правил и интерфейсных страниц, 27 проверок нативного маршрута,
запись и продолжение незавершённой мини-игры в другом процессе прошли.
Общая регрессия: 584 проверки основной игры, 2394 самостоятельного PCK и
пять вариантов первой главы по 33 проверки. PCK проверяет независимые системы;
новый слой работы проверяется основным проектом. Все запуски используют `Dummy`.

Захваты нативного Godot 1366×768 визуально проверены и являются справочными
примерами управляемого тестового мира. Они не относятся к пользовательскому
сохранению. Для показа мастерской тест задаёт вторую карьерную ступень;
в обычной игре её нужно заработать. Остальной маршрут идёт через настоящее
начало песочницы, зеркало, экран денег, поездки и нажатия кнопок мини-игры.

В основной игре остаются прежние сообщения завершения о 63 ObjectDB и
27 ресурсах. В приложенных прошедших логах нет ошибок GDScript, отказов тестов
и других ошибок runtime. Общий рабочий каталог параллельно меняется другими
исполнителями; версии исходников и доказательств закреплены хешами протокола.
