# Проверка города v2

19 октября 2026, Godot 4.7.2. Основная игра: 505 проверок, город: 118 из них, экспортированная основная игра: 9, независимый PCK: 1722; ошибок нет. Пять прохождений первой главы по 33 проверки и восстановление в новом процессе прошли.

Точные результаты и ограничения — в `report.json`, исходные логи рядом. Проверка экспортированной игры запускает `tests/gameplay/city_pack_smoke.gd` по абсолютному файловому пути с `--main-pack`, поскольку сами тесты в поставку не включаются. Экспорт выполнялся существующим Windows Desktop preset, добавлен только include для JSON географии.

В основной игре остаются прежние сообщения ObjectDB/resources при завершении. Они сохранены в логах, не скрыты и не относятся к падению тестов. Автосохранения в тестовых сценах приостановлены; файлы пользовательских слотов не менялись.
