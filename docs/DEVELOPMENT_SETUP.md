# EroInc: среда разработки Windows

Настроено 17 сентября 2026 года. Проект: `F:\GoDot\ero-inc`.

## Как продолжить работу

1. Откройте ярлык **EroInc - Godot** на рабочем столе.
2. Для запуска игры нажмите **F6** для текущей сцены или **F5** для всего проекта.
3. Для работы в VS Code откройте папку `F:\GoDot\ero-inc`. Путь к Godot и Python уже указан в `.vscode/settings.json`.
4. Для сборки откройте в Godot **Проект → Экспорт** и выберите Windows Desktop или Android. Для Android во время разработки используйте отладочный экспорт.

## Сценарные утилиты

В PowerShell из папки проекта:

```powershell
# Справка по сборке диалогов
.\.venv\Scripts\python.exe .\tools\build_prologue_dialogic.py --help

# Пересборка диалогов из исходного документа; перезаписывает таймлайны пролога
.\.venv\Scripts\python.exe .\tools\build_prologue_dialogic.py "C:\путь\Пролог.docx"

# Пересоздание документов с описанием таймлайнов в out
.\.venv\Scripts\python.exe .\tools\build_prologue_timeline.py

# Восстановление зависимостей в существующем окружении
.\.venv\Scripts\python.exe -m pip install -r .\requirements-dev.txt
```

Исходный `Пролог.docx` не найден в проекте и папке Downloads. По умолчанию утилита ожидает его в `docs\Пролог.docx`, либо принимает путь аргументом. Существующие диалоги можно редактировать в Dialogic без этого документа. При настройке утилиты не запускались в режиме генерации, поэтому таймлайны и документы не перезаписывались.

## Оставшиеся задачи проекта

- Quest Weaver предупреждает, что нет узла в группе `inventory_controller`: действия с предметами потребуют подключения инвентаря.
- При завершении проверок без окна Godot сообщает о неосвобождённых ресурсах. Это требует отдельной проверки жизненного цикла объектов в проекте и дополнениях.
- У нескольких старых утилит в `tools` сохранились только `.gd.uid` без самих `.gd`. Установка программ их не восстанавливает.
- Для публикации Android понадобится собственная release-подпись; текущий APK предназначен для отладки. Параметры публикации и идентификатор пакета не изменялись.
