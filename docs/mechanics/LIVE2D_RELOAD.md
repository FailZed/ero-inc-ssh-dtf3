# Повторная загрузка реакционного профиля

28 октября 2026. Подтверждён и исправлен дефект существующего актёра MDRG:
ошибка повторной загрузки могла оставить новый `reactions` рядом со старой
моделью/привязками, а неизвестный параметр удалял уже загруженную модель.
До исправления исходный тест из пяти ошибок дал четыре нарушения целостности.

## Контракт после исправления

Начало `load_reactions` и прямого `load_character` останавливает текущую речь,
закрывает рот и снимает краткий жест. При отказе возвращается именно `false`,
`load_failed` вызывается один раз, `model_loaded` не вызывается. Код причины
доступен в `last_load_error`. Корректные модель, профиль, выражения, значения
одежды и не связанные с речью каналы прежнего экземпляра сохраняются целиком.
Это сохранение здорового состояния при отказе, без замены неизвестной реакции
нейтральной и без другого рендера в качестве fallback.

Новый комплект проверяется на временном скрытом экземпляре существующего
Puppet: JSON/структура, ссылки на MOC/текстуры/физику, форма привязок и реальные
пределы параметров. Только после всех проверок нативная модель и её ресурсы
передаются актёру. Прежняя модель освобождается после принятия новой.
Временный экземпляр всегда удаляется. Новый продуктовый риг, UI или сцена
не создавались; используется тот же исходный ассет `interaction_model`.

После успеха испускается один `model_loaded`, диагностика очищается. Можно
успешно загрузить профиль после любого проверенного отказа. Объект банка
параметров сохраняет идентичность и настройки сглаживания, кадрирование
актёра сохраняется. Допустимые именованные цвета палитры, например `white`,
по-прежнему поддерживаются. Контроллер мастерской `puppet_view.gd` не менялся.

## Проверено

`tests/characters/reload_reactions.gd` проверяет 16 ошибочных вариантов:
невалидные JSON профиля/модели, отсутствующие профиль/модель/MOC/текстура,
неизвестный параметр реакции/привязок, неверные формы контейнеров,
неправильный речевой стиль и отсутствие начального выражения.
Для каждого отказа проверяются целостность, события, остановка речи,
очистка временных узлов и последующая успешная загрузка. Отдельно проверены
прямой модельный API, идентичность банка, кадрирование и первый отказ на
ещё пустом актёре. Все тестовые файлы находятся в отдельном каталоге на E:.
Один тест копирует неизменённый существующий MOC для проверки отсутствующей
текстуры; это временная фикстура, а не новая модель игры.

Узкая регрессия речи/разговора подтверждает прежние skip, остановку рта,
`narrated`, смену выражений и возврат к категории/папке. Увеличенный реальный
рендер нейтрального/smile/concern после передачи модели визуально осмотрен.
Проверки выполнены и из изолированного PCK, без загрузки loose-проекта рядом.
Полная симуляция ради счётчика не запускалась.

Сводка с точными числами, логами и хешами: `LIVE2D_RELOAD_VERIFICATION.json`.
Проверялись перечисленные отказы и нативная загрузка здорового MOC. Произвольные
повреждения внутри двоичного MOC не фаззились: разбор этого формата остаётся
за Cubism SDK. Общая EXE, сохранения, мышь, School, Git и изолированная копия
города не затрагивались. Изменения готовы в исходниках и проверочном PCK.
