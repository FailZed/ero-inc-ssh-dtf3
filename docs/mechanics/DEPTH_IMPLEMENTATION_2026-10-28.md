# Реализованное углубление механик

28 октября 2026. Основание — аудит `QUALITY_AUDIT_2026-10-28.md`. Рабочее дерево совместное: этот проход относится к правилам, данным, регистрации сервисов и тестам. UI, сцены, стили, графика и файлы пользовательских сохранений не редактировались этим агентом. Изменения других агентов в рабочем дереве сохранены.

## Что изменилось для игры

| Система | Реализованный результат |
| --- | --- |
| Учёба | Отдельный прогресс каждого выбранного предмета: посещения, оценочные задания, практика, подготовка, трёхэтапный проект с выбранным подходом, аттестация, сертификаты, следующий модуль. Одинаковое задание нельзя повторно оценить в тот же день. |
| Связь учёбы с работой | Сертификат соответствующего навыка повышает коэффициент зарплаты. Есть сквозная цель на сертификат и проект. |
| Клубы | Дорога и доступность помещения, проверка расписания/потребностей NPC, реальная работа по минутам, резервирование часовой оплаты и пропорциональная выплата при прерывании. Один труд не копируется во все кампании. Бюджетный отказ влияет на мораль только при попытке реальной смены. |
| Цифровые занятия | Осторожный, обычный и быстрый подходы с разной длительностью, шансом, следом и оплатой. Частичный результат клиентских/учебных задач даёт 25% оплаты без полного достижения. Прогноз чистый, повторная выплата исключена. |
| Задания | 12 новых цепочек объединяют город, учёбу, работу, общение, готовку, жильё, семью и клубы. Прогресс зависит от успешных команд, уникальных действий/разных дней и фактически завершённых результатов. |
| Личные проекты | Команда возвращает фактический прогресс и завершение; сквозная цель засчитывается только после окончания. |
| День и бюджет | Читающие запросы для приоритетов, ближайших сроков, доступных наград, бытовых последовательностей и прогноза до 12 действий на изолированной копии мира. Финансовый горизонт учитывает аренду, долги, семью, алименты, активы и проценты по кредиту. |
| Семья | Объяснимые вехи развития, влияние развития на обучение, самостоятельное приготовление еды у старших членов семьи с реальными расходами. Настройки цены и периодов помощи теперь используются из каталога. |
| Личные истории NPC | Общий сюжет зависит от стремлений и навыков, а не только идентификатора. Начатый сюжет остаётся стабильным при изменениях персонажа. |
| Состояние и сохранение | Проверяются новые записи курсов, сертификатов, клубных смен, выплат и уникальных целей. Новая схема без слоя совместимости: базовая 2, основная 10. |

## Проверка

1. `pwsh -NoProfile -File tools/test_mechanics.ps1 -Isolated -Pack` — **2674 проверки, 0 отказов**, импорт и экспорт автономного пакета успешны; Godot **4.7.2**.
2. `python3 tools/test_mechanics_depth.py` — **48 проверок, 0 отказов**. Небольшой изолированный проект собирается из зависимостей основного симулятора, без autoload, сцен и пользовательских сохранений. Этот запуск использует тот же закреплённый runtime, что `tools/godot.ps1`.
3. Проверены дневные лимиты и специализация проекта, требования сертификата, повторные награды, прерывание и продолжение смены после JSON-сохранения, приоритет обязательного расписания, разные цифровые подходы и частичный результат, уникальность прогресса заданий, влияние квалификации на зарплату, чистота прогноза, семейные расходы и устойчивость личной истории.
4. Полный автономный набор включает семидневную симуляцию 100 NPC. Это проверка целостности и воспроизводимости, не доказательство баланса экономики на 90 игровых дней и не человеческая оценка интереса.

## Что остаётся за пределами этого прохода

Интерфейс новых действий передаётся через `DEPTH_UI_CONTRACT.md`. Существующие кнопки используют изменённую логику, но новые варианты ещё нужно вывести на экраны и проверить в игре. Этот результат не означает, что все 275 пунктов старого реестра получили законченный UX или полный числовой/контентный паритет.

Дальнейшие задачи исходного аудита остаются актуальны там, где нужны авторский контент и отдельные проверки: профессиональные ситуации на старших ступенях, более разнообразные события и реакции, расширение ассортимента, визуальные состояния/гардероб, звук и длительный баланс. Для оценки удобства и интереса нужен проход через готовые экраны с несколькими разными игровыми целями. В рамках этого изменения такие результаты не заявляются.
