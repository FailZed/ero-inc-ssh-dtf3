# EroInc — растровые UI-референсы

Это **визуальные концепты**, а не скриншоты работающей игры. Значения, подписи и действия в игровом HUD выводятся настоящими контролами Godot. Телефон сохраняет собственный интерфейс.

| Состояние | Референс | Применение |
| --- | --- | --- |
| Основной HUD | [hud-reference-v5.png](hud-reference-v5.png) | Утверждённая пользователем композиция сцены: компактные потребности снизу, время с календарём и деньгами сверху, предметные маркеры действий. |
| Кровать | [hud-bed-menu-v5.png](hud-bed-menu-v5.png) | Контекстный выбор у объекта и ползунок длительности сна вместо заранее написанных «8 часов». |
| Сумка | [inventory-rpg-v4.png](inventory-rpg-v4.png) | Отдельный RPG-инвентарь с сеткой предметов и подробностями выбранного предмета. |
| Книга | [journal-v4.png](journal-v4.png) | Предметная навигация по главам «Личное», «Город», «Истории»; сумки внутри нет. |

В игре книга использует отдельную прозрачную основу [book_blank.png](../../../assets/textures/ui/book/book_blank.png) поверх **текущей живой сцены**. Кнопки и надписи поверх неё остаются интерактивными. При открытии книги фон локации не заменяется.

В игровом HUD видны все девять показателей: здоровье, силы, жажда, голод, гигиена, туалет, сон, досуг и общение. Блок квеста временно скрыт. Верхний ряд содержит локацию, календарь рядом со временем, дату, деньги и меню. Нижний ряд содержит телефон, сумку, книгу и разделы. Каждая доступная группа действий отображается на сцене маркером в стиле «Поспать»; если у объекта несколько действий, наведение мыши или касание открывает контекстное меню. Одно действие выполняется непосредственно кнопкой маркера. Меню кровати всегда предлагает длительность сна на ползунке.

Перечень реальных локаций и действий на сцене, позиции маркеров и поля для новых задач: [location_interactions.json](../../../data/ui/location_interactions.json). Позиции маркеров читаются HUD уже сейчас; `add_actions` и `add_quests` служат для описания будущего наполнения.

Визуальная основа проекта: рисованная ночь, сине-чёрные материалы, тонкая стально-голубая кромка, почти белый текст, бледно-голубой выбор и редкие оранжевые световые акценты. Общие правила: [STYLE.md](../STYLE.md).
