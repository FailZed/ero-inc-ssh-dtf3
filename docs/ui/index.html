Правила интерфейса
  • Одна задача на экране; полная навигация открывается по F1.
  • Светлая типографика, прозрачные тёмные поверхности, минимум рамок. Художественная основа EroInc сохранена.
  • Q открывает план действий. Shift + действие добавляет его в очередь. Пустой план скрыт.
  • Телефон — отдельное устройство с приложениями и сменными обоями. Сумка использует сетку предметов; дневник — разворот с одной выбранной записью.
  • Растровые изображения ImageGen встроены в игровые окна. Надписи, кнопки, фокус и действия работают средствами Godot.
  • Просмотр окон не расходует время. Игровые действия вызывают существующую симуляцию.

Спецификация · Результаты проверок

Настоящие снимки Godot из отдельного тестового мира. Это не художественные макеты и не сохранённое прохождение игрока. Разрешения с сокращённым обзором содержат основные окна и увеличенный текст.
