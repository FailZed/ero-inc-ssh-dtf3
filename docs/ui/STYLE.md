# Текущие правила UI EroInc

Обновлено 28 октября 2026 по прямым уточнениям пользователя.
Внешний ориентир — его [ночная сцена](references/approved-hud.png).
Ориентир удобства — просмотренная запущенная School и предоставленные пользователем
снимки её компактных списков [людей](references/school-user-people.png) и
[действий](references/school-user-actions.png). Это референсы, не экраны EroInc.

- Сцена остаётся главным изображением. Вверху находятся время, дата, деньги и меню;
  внизу — лёгкие иконки показателей и быстрых разделов.
- Действия, находящиеся рядом люди и выходы переключаются внутри одной небольшой
  правой панели. Не открывать большой раздел для каждого обычного действия.
  Высота зависит от содержимого; длинные списки прокручиваются, панель сворачивается.
- Сумка — список принадлежащих игроку вещей с количеством и весом. Нет пустых
  декоративных ячеек. Выбор открывает описание и подходящие действия рядом;
  рисунок вещи небольшой. Надетая вещь предлагает снятие, выбранная еда — использование.
- Сохранены ночные рисованные окружения, сине-чёрная прозрачность, тонкая
  стальная граница, светлая типографика, бледно-голубой выбор и редкий оранжевый акцент.
  Общая поверхность UI.surface() кодовая; растровая рамка windows-v2 больше не используется.
- Основная типографика — PT Serif; шрифт и OFL находятся в assets/fonts/pt-serif.
  Телефон сохраняет Android-подобные растровые иконки, свои обои и шрифт без засечек.
- Назад/Esc закрывает текущий уровень; выбор вещи и фильтры сохраняются при возврате.
  Просмотр списков не расходует время, предметы или RNG. Игровые изменения выполняет Gameplay.
- Модальные окна удерживают клавиатурный фокус. Подтверждения удаления и замены
  сохранений выбирают отмену по умолчанию. Пользовательские слоты при UI-проверках не меняются.
- Проверять короткие и длинные списки, увеличенный текст, клавиатуру и три разрешения.
  Снимки для атласа — нативный Godot в одноразовом тестовом мире, не прохождение игрока.

Текущий узкий протокол: test-ui.log, compact-{1920,1366,ultrawide}.log.
Предыдущий общий обзор: approved-scene-*; он не заменяет визуальную проверку
последних изменений. Физический геймпад не проверялся.

Запись наблюдений School для авторов мест: ../coordination/ui-ux.md.
Никакие тексты, изображения или код School в игровой runtime не переносились.

Remote book/companion functionality is merged into the current compact UI;
older scene hotspots and alternative HUD layout are superseded. Book: B or
the sections menu; the existing wait shortcut still advances15minutes.
