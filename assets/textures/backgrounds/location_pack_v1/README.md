# EroInc — склад, квартира и улица · v1

9 PNG-фонов в манере исходного `warehouse_exterior_night.png`. Использован встроенный ImageGen. В этот набор входят исходный экстерьер, три ранее созданных интерьера и пять новых изображений. Промпты пяти новых изображений и происхождение каждого файла: [manifest.json](manifest.json).

[Открыть галерею](index.html).

## Настроение по сценарию

- Склад: холод, пыль, изоляция; луна через прорванную крышу. Отдельный ракурс вверх соответствует пробуждению на полу.
- Квартира ночью: 03:20, тревога после кошмара; слабый уличный свет через шторы, тёмный порог ванной, затем включённая лампа.
- Квартира утром: сентябрьское солнце, поздний подъём; сохранены ракурс и расположение мебели ночной спальни.
- Дом и улица днём: тихий жилой район, солнце после двух недель непогоды, старые фасады и ограды.
- Улица вечером: возвращение с друзьями, прохлада, темнеющее небо и жёлтые фонари. Сохранена архитектура дневного фона.

Дом здесь — нынешняя съёмная квартира героя. Семейный дом из детского воспоминания в этот набор не входит. Конкретный фасад — художественная интерпретация описанного жилого района. Фоны свободны от персонажей: их эмоции и движение можно добавлять отдельными спрайтами.
