Open scenes/browser.tscn (F6 in an existing project). Each model also has a reusable .tscn.
runtime/live2d_pointer.gd supports model-specific interaction parameters and the no-clothing rig preset.
Models require compiled gd_cubism 0.9+ in res://addons/gd_cubism/.
The export helper includes raw MOC/JSON/texture files in packaged games.
archive/ is ignored by Godot and is not packaged into games by this helper.
Unity C#/IL2CPP, Animator graphs, triggers and custom shaders are not automatically translated.
Use import_report.json and the archived exporter report for unresolved items.
